## Что проверено

API принимает один MOV через multipart, возвращает 202 с идентификатором задачи,
проверяет `X-API-Key` до чтения тела и ограничивает доступ владельцем задачи.
Загрузка, очередь и исполнение входят в общий срок до 300 секунд. Зависший анализатор
завершается отдельным процессом; ошибка не подменяется отрицательным вердиктом.
При отсутствии модели результат — `failed/model_unavailable`.

Сервер извлекает JPEG из реального декодированного видео, использует фактические PTS,
проверяет согласованность verdict/events и неизменность рабочей копии видео по SHA256.
Доказательство происхождения кадра не является доказательством правильности описания.
Очередь, загрузка и хранимые результаты ограничены; приватные копии очищаются.

Offline evaluator использует существующий split, проверяет SHA и переданные группы,
изолирует нейтральное имя файла от разметки, сохраняет конфигурацию и хеши.
Ошибки, таймауты и неполные ответы учитываются отдельно от confusion matrix,
публикуется coverage. Holdout требует явного разрешения.

## Оставшиеся ограничения и следующий шаг

1. **NOT RUN:** end-to-end распознавание через новый API с Qwen, независимая оценка
   реальных ошибок, новые GitHub Actions Ubuntu/Windows и публичная HTTPS-проверка.
2. **NOT VERIFIED:** смысловое родство сцен. Проверены точные дубликаты и явно заданные
   группы; отсутствующие группы не угадываются автоматически.
3. API рассчитан на один worker, результаты живут в памяти до TTL/count/64 MiB limit.
   Процесс анализатора не является sandbox; отделённые процессы ему создавать нельзя.
4. Offline evaluator имеет кооперативный deadline и не прерывает зависший callable.
   Принудительное завершение реализовано в HTTP worker, не во всех произвольных callback.
5. Тип пользовательских кредитов NVIDIA/Brev — UNKNOWN, применимость к VM, баланс и
   цена не подтверждены. Сервер не создан; загрузка данных провайдеру не разрешалась.
6. Следующий шаг: короткая человеческая сверка спорных development-ответов в плеере,
   затем локальный адаптер с ограниченным структурированным выводом и явным отказом
   при обрезании/неполноте. Сравнивать выборку кадров по временным окнам на development,
   не превращать редкие описательные кадры автоматически в полный анализ. Holdout закрыт.

Итог: **локальный технический каркас проверен; конкурсное качество NOT FULLY VERIFIED**.
