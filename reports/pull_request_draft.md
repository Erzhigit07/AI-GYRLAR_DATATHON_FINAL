## Описание для публикации

Шаблон расширен для задач с положительной асимметричной целью и оценкой ошибок
в логарифмическом масштабе. Добавлены Ridge, явно включаемый `target_transform=log`
и метрика `log_rmse`. По умолчанию преобразование отключено; прежнее поведение
классификации, обычной регрессии и baseline сохраняется.

### Изменения

- Log-преобразование цели выполняется внутри TransformedTargetRegressor, а predict
  возвращает исходный масштаб. В log-режиме baseline — геометрическое среднее train.
  Log-RMSE вычисляется по натуральным логарифмам цен, не через log1p; некорректные
  цены отклоняются. Направление сравнения с baseline учитывает минимизацию ошибки.
- Предобработка остаётся в sklearn Pipeline и обучается на train-части. Refit
  выполняется только по явному запросу; метрики сохраняют смысл holdout-оценки.
  Предупреждения обучения и оценки сохраняются в warnings.json и выводятся при запуске.
- Изолированные конфигурации и скрипты Titanic/House Prices, аудит Titanic,
  фактические учебные отчёты. Выбор House Prices по внутренним пяти фолдам выполняется
  до оценки внешнего holdout. Специальная логика датасетов не внесена в src.
- Тесты log-RMSE, Ridge/log/refit, baseline, ограничений конфигурации, семантики
  CSV-пропусков и сохранения предупреждений. README описывает отдельный House Prices
  CLI и явно обозначенный совместный аудит, который дополнительно требует Titanic.
- Актуализирована инструкция checkout; добавлен отчёт проверок запуска с нуля.
  Новых инфраструктурных компонентов или зависимостей не добавлено.
