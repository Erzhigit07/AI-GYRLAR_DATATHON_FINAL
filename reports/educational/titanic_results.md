## Процедура и предобработка

До обучения зафиксированы две конфигурации, seed=42 и список семи признаков:
Pclass, Sex, Age, SibSp, Parch, Fare, Embarked. Pclass явно читается как категория.
Выбор признаков и гиперпараметров после просмотра holdout не менялся.

Основная оценка — GroupShuffleSplit по Ticket: **714 train / 177 validation**.
Дополнительная — стратифицированный random split: **712 / 179**. Время для
временной валидации не задано. Все модели внутри каждого split оценены на одних строках.

Существующий Pipeline заполняет числовые пропуски медианой, масштабирует числа,
заполняет категории модой и применяет one-hot. Неизвестные категории допускаются.
Статистики обучены только на train; сохранённые медианы, средние scaler и категории
сверены с train. CatBoost использует тот же one-hot, а не нативные категории.

Baseline: наиболее частый класс (0). Logistic Regression: C=1, max_iter=2000.
Random Forest: 300 деревьев, min_samples_leaf=2. CatBoost: 300 итераций,
depth=5, learning_rate=0.05. Остальные параметры сохранены в metadata.json.
Тюнинга, подбора порога, использования скрытых ответов и refit на всех данных не было.

## Качество данных и EDA

- Train: 177 пропусков Age, 687 Cabin и 2 Embarked; Survived без пропусков,
  549 значений 0 и 342 значения 1. Полных дубликатов нет, PassengerId уникален.
- Test: 86 пропусков Age, 327 Cabin и 1 Fare. ID уникальны и не пересекаются с train.
- Бесконечных числовых значений в train не обнаружено. IQR отметил 11 Age,
  46 SibSp и 116 Fare для проверки, а не удаления. Для Parch IQR=0, этот критерий
  неприменим; отсутствие IQR-флага не означает отсутствие аномалий.
- У Name высокая кардинальность. Name/Ticket/Cabin не включены в модель;
  Cabin исключён заранее, а не по результатам holdout.
- Целевой EDA выполнен только на 714 строках обучающей части основного split.
  В ней доля выживших: женщины 73.6% (250 строк), мужчины 18.1% (464 строки);
  класс 1 — 61.3% (173), класс 2 — 47.3% (148), класс 3 — 23.4% (393).
  Это наблюдаемые связи, не причинные эффекты.

Сохранены отчёты качества train/test/обучающей части, восемь распределений и
матрица числовых корреляций. Ни одна строка не удалена, исходные значения не исправлялись.

## Аудит возможных утечек

| Проверка | Group по Ticket | Random |
| --- | ---: | ---: |
| Общие Ticket между train и validation | 0 | 61 |
| Строки validation с таким Ticket | 0 | 67 |
| Общие семейные прокси | 4 | 41 |
| Строки validation с таким семейным прокси | 4 | 46 |

Семейный прокси — фамилия + заявленный размер семьи для пассажиров с родственниками;
одиночки имеют отдельные ключи. Такой ключ может объединять однофамильцев и пропускать
родственников. Поэтому group split по Ticket не доказывает полную независимость семей.
Отсутствие прямой утечки target и корректность train-only предобработки проверены,
но отсутствие всех возможных связей между объектами не доказано.

Survived/PassengerId/Name/Ticket/Cabin отсутствуют среди модельных признаков.
Ни test, ни его пример submission, ни внешние списки выживших не участвовали в fit.
Доля выживших на group-train 37.54%, на group-validation 41.81%: split не стратифицирован,
состав групп влияет на baseline и оценку. Это нужно учитывать при сравнении моделей.

## Анализ ошибок и переобучения

На основном split CatBoost: **TN=94, FP=9, FN=26, TP=48**. Пропущены 26 из 74
выживших, recall=64.86%. У Logistic Regression FP=11/FN=28, у Random Forest FP=9/FN=30.

Ошибки CatBoost по подгруппам основного validation:

- Женщины: 18/64 (28.1%); мужчины: 17/113 (15.0%).
- Класс 1: 9/43 (20.9%); класс 2: 4/36 (11.1%); класс 3: 22/98 (22.4%).
- Age отсутствует: 6/37 (16.2%); Age известен: 29/140 (20.7%).

Не следует заключать, что пропуски полезны: состав подгрупп различается, сравнение
наблюдательное. В группе старше 60 лет всего 4 строки — её 0 ошибок не подтверждает
надёжное качество. Разбор по подгруппам выполнен после оценки и не использован для тюнинга.

| Модель | Train accuracy | Validation accuracy | Разрыв, п.п. |
| --- | ---: | ---: | ---: |
| Logistic Regression | 81.93% | 77.97% | 3.97 |
| Random Forest | 90.76% | 77.97% | 12.79 |
| CatBoost | 91.32% | 80.23% | 11.09 |

У деревьев заметный разрыв train/validation. Это основание проверить регуляризацию
и устойчивость на групповой CV, а не утверждать, что найден универсально лучший алгоритм.

## Что требует доработки в шаблоне

1. Валидация: связанные компоненты Ticket/семей и групповая CV, если задача требует
   оценки новых независимых групп. Один holdout дал неустойчивое ранжирование моделей.
2. Метрики: хранить признак undefined рядом с нулём precision baseline; предупреждение
   сейчас сохраняется экспериментальным скриптом, но не универсальным train.
3. Диагностика: общий API для confusion matrix, подгрупп и train/validation-разрыва;
   сейчас этот анализ вынесен в отдельный учебный скрипт.
4. Конфигурация: явные семантические типы признаков и назначение эксперимента
   (educational/competition). Pclass сейчас требует dtype через read_options.
5. CatBoost: сравнение нативных категорий с общим one-hot только при необходимости
   конкретной задачи; текущая реализация работоспособна, но не обязана быть оптимальной.

**Подтверждено:** сквозной сценарий табличной бинарной классификации на реальном наборе
работает. **Не подтверждено:** готовность к любой неизвестной задаче, масштабируемость
на большие данные, регрессия на реальном датасете и соблюдение ещё неизвестных правил DATATHON.
